## 管件安装

### 紫铜环

PF16，PF5（可选卡箍或紫铜环）

剪管->放入紫铜环和管件（紫铜环距离管口约0.8cm）->压接->用压痕通规检查，刚好贴合半圆即ok

### 卡箍

PF5（可选卡箍或紫铜环）

剪管->放入卡箍和管件（卡箍距离管口约0.8cm）->压接

### 压接

PF5，PF7，PF15

剪管->插管连接->压接->用压痕通规检查

### 滑紧式

PF2/PF3

剪管->套上铜套，扩口（多扩几次，每次旋转30°）->插管连接->滑进，推入铜套

### 扩口式

PF6

剪管->套上记忆套，扩口（多扩几次，每次旋转30°）->插管连接

## 市政系统

### ★★★HDPE给水管四种连接方式

- 热熔承插：适用于较小管径（≤DN110），使用热熔承插器，常用于空间较小的室内或室外施工。 

- 热熔对接：适用于较大管径（≥DN75），使用热熔对接机，推荐用于空间较大的室外施工。

- 电熔连接：适用于所有规格，使用电熔焊接机，适用于空间较小的室内外施工。  

- 法兰连接：适用于DN40~DN1200规格，通过法兰盘与垫片连接，常用于不同管材或管材与阀门之间的连接。  

### ★★日丰编制软管优点

- 螺帽材质：日丰软管除L型外均采用铜螺帽，承压能力强，不生锈；劣质品牌常采用201不锈钢螺帽，承压差且易生锈。  

- 编织网做工：日丰采用7股优质不锈钢丝紧密排列编织，防爆防锈，安全耐用；劣质软管编织粗糙，易出现跳丝、断丝、扎手现象，极易爆裂。

- 内管材质：日丰精选优质EPDM橡胶内管，环保卫生无异味，耐高温可达+90℃，抗老化性强；劣质软管采用劣质或再生橡胶，易老化开裂，甚至污染水质。

## 质量控制

验证多层管道连接可靠性与长期稳定性

- **热循环试验**：在10 bar压力下，将水温在+20℃（保持15min）与+95℃（保持 15 min）之间交替循环5,000次，验证系统在热胀冷缩下的抗疲劳和密封稳定性。  

- **压力循环试验**：在（+23±2℃）温度下，以30次/分钟的频率，将系统压力在0.1MPa~1.5MPa之间脉冲循环10,000次，检验系统在动态压力冲击下的结构完整性。  

- 真空气密性试验：在+23℃下，将管道系统抽真空至-0.08MPa并保持1小时，要求压力变化不超过0.005MPa，验证接头的负压密封性能。

- 拉拔试验：向管段充入0.03MPa压力后，按标准施加规定的轴向拉伸载荷，验证管件与管材连接处在机械拉伸下无泄漏、无相对轴向位移。

### ★★★管材生产流程（挤塑）

混料**→**挤出**→**冷却定径**→**打印**→**缠绕膜**→**切管

| 工序     | 设备         | 要点                                                         |
| :------- | :----------- | :----------------------------------------------------------- |
| 混料     | 混料机       | 将大宗原料及辅料按比例混合，输出PVC管材粉状混料。            |
| 挤出     | 挤出机       | 料斗进料注入模腔受热熔融；螺杆推动熔融料；经挤出模头初步挤出管材。 |
| 冷却定径 | 真空定径机   | 管材经过定径套定径，进入真空箱；真空环境中冷却、定径。       |
| 打印     | 激光打印机   | 在冷却后的管材表面打印生产日期、批次等信息。                 |
| 缠绕膜   | 缠绕膜打包机 | 牵引机带动管材经过打包机，表面缠上PE材质缠绕膜。             |
| 切管     | 自动切割机   | 将管材剪切成需要长度；切割端口平整、无毛刺。                 |

### ★★★管件生产流程（注塑）

混料**→**造粒**→**吸料溶胶**→**合模射胶**→**开模脱模**→**打包

| 工序     | 设备           | 要点                                                       |
| :------- | :------------- | :--------------------------------------------------------- |
| 混料     | 混料机         | 大宗原料及辅料按比例混合，输出粉状混料。                   |
| 造粒     | 造粒机组       | 粉状混料注入小型挤出机，挤出固态条状料，冷却后粉碎成粒料。 |
| 吸料溶胶 | 注塑机         | 粒料上料、高温熔融；螺杆转动带动熔融料往前，准备注入模具。 |
| 合模射胶 | 注塑机         | 熔融料经热流道进入模具；模具内成型，内切水口。             |
| 开模脱模 | 注塑机         | 打开模具，注塑完成；模具腔体内已完成剪水口。               |
| 打包     | 流水线、打包机 | 履带带动成品集中打包；粘连水口料需清理。                   |
